# Cluster@SIPg

Public information for researchers and students interested in the SIPg research
computing pilot. This repository is public. Do not put credentials, personal
information, internal addresses, unpublished data, or operational details here.

## Current status

As of 22 November 2026, Cluster@SIPg is a Stage 1 pilot. Individual CPU and GPU
smoke tests have passed on the pilot nodes. General user access and consistent
cross-node identity are still being finalized. This is not an announcement that
general access is open.

## Requesting an account

1. Ask your SIPg supervisor or designated group contact to confirm that you are
   eligible to request access.
2. Ask them for the approved private account-request channel and the information
   required for the request. The request process is being finalized and its
   channel is not published in this public repository.
3. Submit the request only through the private channel provided to you. Do not post
   account requests, personal details, passwords, keys, or tokens in public
   GitHub issues or discussions.
4. Wait for explicit approval and account-specific instructions from the
   cluster administrators before attempting to use the service.

If your supervisor or group contact cannot identify the current request
channel, ask them to contact the cluster administrators and confirm the
approved process before you submit a request.

## After approval

Administrators will provide access instructions and point approved users to the
current internal user guide. Access, available resources, and usage rules are
subject to the pilot's readiness and administrator approval.
