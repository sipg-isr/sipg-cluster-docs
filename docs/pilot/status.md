# Stage 1 Pilot Status

Last checked: 22 November 2026

Cluster@SIPg is being piloted with the initial server group. Individual CPU and
GPU smoke tests passed on each pilot node. This confirms those individual tests
only; it does not establish general service availability or consistent
cross-node identity.

General user access remains under preparation. Wait for an explicit account
approval and access instructions before attempting to use the cluster. The
private user guide is provided to approved users by the administrators.
