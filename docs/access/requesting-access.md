# Requesting Cluster Access

## Current status

As of 22 November 2026, Cluster@SIPg is a Stage 1 pilot. Individual CPU and GPU
smoke tests have passed on the pilot nodes. General user access and consistent
cross-node identity are still being finalized. General access is not open.

## Request steps

1. Ask your SIPg supervisor or designated group contact to confirm whether you
   are eligible to request access.
2. Ask them for the approved private account-request channel and the information
   required for the request. The request process is being finalized; its channel
   is not published in this public repository.
3. Submit the request only through the private channel provided to you. Do not
   post account requests or personal details in public GitHub issues or
   discussions.
4. Wait for explicit approval and account-specific instructions before
   attempting to use the service.

If your supervisor or group contact cannot identify the current request
channel, ask them to confirm the approved process with the cluster
administrators before you submit a request. Never send passwords, private keys,
or tokens with an access request.
